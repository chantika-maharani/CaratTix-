CaratTix – Sistem Booking Tiket Konser

CaratTix adalah website pemesanan tiket konser berbasis **PHP dan MySQL**.
Website ini memiliki dua bagian utama yaitu **user** untuk melakukan pemesanan tiket dan **admin** untuk mengelola data konser serta tiket.


Fitur Website :

- User

* Melihat daftar konser
* Melakukan booking tiket
* Mengecek status booking

- Admin

* Dashboard admin
* Mengelola data konser
* Mengelola tiket
* Melihat data booking user

Teknologi yang Digunakan:

* PHP
* MySQL
* Bootstrap 5
* HTML
* CSS


Cara Menjalankan Project:

1. Install XAMPP
2. Masukkan folder "caratix" ke dalam folder "htdocs"
3. Import database yang ada di folder **database**
4. Jalankan website di browser

Halaman User: http://localhost/caratix

Halaman Admin: http://localhost/caratix/admin
